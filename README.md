# Sešit slovíček

Тренажёр чешского языка по учебнику «Česky krok za krokem 1» (сейчас — уровень A1, уроки 1–12): слова, грамматика с упражнениями, тексты с тестами и разговорник.

Открыть: https://sbaiku.github.io/cestina/ — на телефоне «Поделиться → На экран „Домой“», и оно откроется как приложение.

## Разделы

- **Тренировка слов** — «Написать», «Выбрать перевод», «Вставить слово». Слово выучено в тренировке после 5 верных ответов, за раз до 10 слов, ошибки повторяются в конце. Ответ без диакритики засчитывается как «почти верно». Кнопка «Знаю это слово» сразу отправляет слово в выученные.
- **Словарь** — слова по урокам с мини-шкалами; кнопки «Знаю» и «Знаю все слова урока».
- **Выученные** — «Могу написать» и «Знаю перевод», у каждой части своя кнопка «Повторить заново».
- **Правила** — объяснение с таблицами и 30 упражнений.
- **Чтение** — тексты по темам учебника (пересказ своими словами), тест из 10 вопросов, «Слушать текст».
- **Фразы** — разговорник, карточки RU→CZ или CZ→RU, «Знаю» +1 / «Ещё учу» −1, выучена на 5. Фразы даны в женском роде, мужской вариант — в примечании.

Во всех правилах, текстах и фразах чешские слова подчёркнуты пунктиром: нажми — появится перевод и начальная форма (из `words.json`, глоссариев текстов и `lex.json`). Если слова нет — ссылка на Google Переводчик.

## Как устроено

- `index.html` — всё приложение на чистом JS, без сборки и без сервера.
- `data/*.json` — всё содержимое. Чтобы добавить слова, правила, тексты или фразы, поправь JSON и запушь в `main`: GitHub Pages обновит сайт за минуту-две.
- PWA: `manifest.webmanifest`, иконки в `icons/`, `sw.js` (сначала сеть, потом кэш — работает и офлайн).
- Озвучка — `speechSynthesis` браузера, язык `cs-CZ` (нужен чешский голос в системе; на iPhone и Android он обычно есть).
- Прогресс хранится на устройстве (`localStorage`). Кнопки внизу страницы сохраняют его в файл и загружают обратно — так его можно перенести на другое устройство.

## Форматы данных

`data/words.json` — массив слов:

```json
{ "id": "polevka", "cs": "polévka", "ru": "суп", "lesson": "03 · Jídlo a pití · стр. 25–32", "n": 132,
  "ex": "Dám si česnekovou ___.", "exForm": "polévku", "exRu": "Я возьму чесночный суп.", "alt": ["…"] }
```

- `id` — латиница, цифры и дефис, уникальный и **неизменный**: на нём держится прогресс.
- `lesson` — название урока; номер в начале (`01 ·`, `02 ·`) задаёт порядок.
- `ex` содержит `___` на месте слова; `exForm` — форма слова в этом предложении, если отличается от `cs`; `alt` — другие принимаемые ответы при письме. Без `ex` слово не участвует во «Вставить слово».

`data/rules.json` — массив правил: `id`, `n` (порядок), `level`, `lesson`, `title`, `summary`, `task`, `body` (блоки `{h}`, `{p}`, `{note}`, `{list: []}`, `{table: {head, rows}}`, внутри можно `**жирный**`), `exercises` (30 штук: `{q, a, opts?, why?, ru?, alt?}`; `q` содержит `___`; без `opts` ответ вписывается). **Новые упражнения добавляй в конец**, не меняя порядок старых: прогресс хранится по номеру упражнения.

`data/texts.json` — тексты: `id`, `n`, `level`, `lesson`, `title`, `summary`, `paragraphs` (массив абзацев, абзац — массив предложений `{cs, ru}`, всего 20–25), `glossary` (`{cs, ru}`), `questions` (10 штук `{q, a, opts, ru?, why?}`).

`data/phrasebook.json` — темы разговорника: `id`, `n`, `title`, `phrases` (`{cs, ru, note?}`). **Новые фразы добавляй в конец темы**: прогресс хранится по номеру фразы в теме.

`data/lex.json` — словарь словоформ для подсказок: `"форма": {"ru": "перевод", "base": "начальная форма / пояснение"}`, ключ в нижнем регистре. Слова из `words.json` и глоссариев подхватываются автоматически, поэтому в `lex.json` нужны только остальные формы. **При добавлении текстов и правил дополняй `lex.json` всеми новыми формами**, иначе по нажатию будет ссылка на переводчик.

## Как добавить материалы

1. Новый урок — добавь слова в конец `words.json` с новым `lesson`, правила в `rules.json`, текст в `texts.json`.
2. Проверь, что JSON валиден (например, открой файл в браузере или `python3 -m json.tool data/words.json`).
3. Закоммить и запушь в `main`.
